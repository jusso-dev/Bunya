Validation findings (2)
  • BUNYA.COMP.005warning
    Add a Log Analytics workspace and wire diagnostic settings from each resource into it.ISM-1233 requires event logs to be centrally stored and protected against unauthorised modification. Essential Eight Maturity Level 2 expands this to include security-relevant events from cloud workloads. Without a Log Analytics workspace there is no sink for diagnostic settings, Sentinel, or longer-term retention, which leaves the deployment unable to demonstrate the control.
  • ISM.1233warning
    Add a Log Analytics workspace and wire diagnostic settings from each resource into it.Control ISM-1233 directs that event logs are retained centrally and protected from unauthorised modification. In Azure this is realised by sending diagnostic settings into a Log Analytics workspace (often combined with Sentinel for SIEM). A graph that contains workloads but no workspace has no sink for these logs and therefore cannot demonstrate the control.
